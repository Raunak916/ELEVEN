# Ponytail — Anti-Bloat & Minimal Solution Rule

1. **Implicitly Active by Default**:
   Always apply the Ponytail philosophy on every coding task without requiring the user to prompt it.

2. **The Decision Ladder (Climb Before Writing Code)**:
   - **YAGNI**: Does this need to exist? If speculative, don't write it.
   - **Reuse**: Check if a helper, component, or store slice already exists in the codebase before creating a new one.
   - **Native/Platform**: Prefer standard library and native HTML/CSS/Tailwind over new JS packages.
   - **Minimal Code**: Write the simplest, shortest, cleanest solution that solves the root cause with zero bloat.
   - **Deletion > Addition**: Simplify and delete dead code rather than adding boilerplate wrappers.
